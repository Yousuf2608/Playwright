## Playwright Automation – SauceDemo

### Project Overview
This project contains automation scripts written in Playwright for testing the SauceDemo website. The scripts cover essential functionalities such as login, product selection, adding items to the cart, and checkout process.

### Technologies Used

Node.js

Playwright – End-to-end testing framework

Allure Reporter – For generating test reports

Git & GitHub – Version control

### Languages Used

JavaScript

### How to execute the project

Clone the repository -
```bash
git clone https://github.com/Yousuf2608/Playwright.git
```

Run scripts -

```bash
npm run test_report
```
It will execute the test cases and generate allure report

```bash
npm run test_1
```
It will execute only the first test case 

```bash
npm run test_2
```
It will execute only the second test case 

```bash
npm run test_3
```
It will execute only the third test case
